# 声の学習用 読み上げ台本

## 録音のしかた

- 静かな部屋で、スマホのボイスメモか Windows のサウンド レコーダーで録音します
- マイクと口の距離は20〜30cmくらい。録音中は距離を変えないようにします
- **1文読んだら、1秒ほど間をあけて**次の文へ進みます（あとで自動で1文ずつに区切るため）
- 読み間違えたら、その文をもう一度読み直せば大丈夫です（止めなくてよいです）
- **4つのファイルに分けて**録音し、`voice_data/recordings/` に置いてください
  - `normal`（ふつう）、`happy`（うれしい）、`calm`（穏やか）、`sad`（悲しい）
  - ファイル名の例: `normal.m4a`、`happy.m4a`（形式は wav / m4a / mp3 どれでも可）
- 感情の文は、演技しすぎず、その気持ちのときの自然な話し方で読みます

全部で2〜3分ほどです。

---

## 1. ふつう（normal）　普段の会話の調子で

1. おはようございます、今日もよろしくお願いします。
2. 駅前の新しいパン屋さんに、朝一番で行ってみました。
3. 昨日は雨だったので、一日中家で本を読んでいました。
4. ちょっと待ってね、今そっちに行くから。
5. 来週の火曜日は、午後三時から打ち合わせがあります。
6. ペットボトルのお茶を、ぴったり百二十円で買いました。
7. 図書館で借りた料理の本を、明日までに返さなきゃ。
8. 自転車のタイヤがパンクしてしまって、歩いて帰りました。
9. 冷蔵庫に、キャベツと卵と牛乳が入っています。
10. 東京から大阪までは、新幹線でおよそ二時間半です。
11. 窓を開けると、涼しい風が入ってきて気持ちいいね。
12. しばらく会っていなかった友達から、急に連絡が来ました。
13. この道をまっすぐ進んで、二つ目の信号を右に曲がってください。
14. 週末は、近所の公園でゆっくり散歩するのが好きです。
15. パソコンの調子が悪くて、何度も再起動しました。
16. 夏休みには、祖父母の家で花火をするのが楽しみでした。
17. ねえ、それってどういう意味なの？
18. 晩ごはんは、みんなで手作りのぎょうざを包みました。
19. 少し疲れたから、コーヒーを飲んでひと休みしよう。
20. 明日の天気は、晴れのち曇りになるそうです。

## 2. うれしい（happy）　うれしい、楽しい気持ちで

1. わあ、本当に？すごくうれしい！
2. やったね、ずっと頑張ってきたもんね。
3. 今日のお弁当、すっごくおいしかったよ。
4. 久しぶりに会えて、本当に楽しかった！
5. プレゼントありがとう、大事に使うね。
6. 見て見て、きれいな虹が出てるよ！
7. 合格おめでとう、自分のことみたいにうれしいよ。
8. 次の旅行、今からわくわくしてるんだ。

## 3. 穏やか（calm）　相手をいたわる、落ち着いた気持ちで

1. そっか、今日も一日おつかれさま。
2. 大丈夫だよ、ゆっくりでいいからね。
3. 無理しないで、たまには休んでいいんだよ。
4. うんうん、ちゃんと聞いてるよ。
5. 焦らなくても、きっとうまくいくと思うな。
6. あったかいお茶でも飲んで、少し落ち着こうか。
7. 話してくれて、ありがとうね。
8. 今夜はぐっすり眠れるといいね。

## 4. 悲しい（sad）　さみしい、残念な気持ちで

1. そうなんだ、それはさみしかったね。
2. もう会えないと思うと、胸が苦しくなるよ。
3. せっかく準備したのに、中止になっちゃった。
4. あのころに戻れたらいいのにな。
5. ごめんね、力になれなくて。
6. ひとりで帰る道は、なんだか長く感じるね。
7. 大切にしていたものを、なくしてしまったんだ。
8. いつかまた、笑って話せる日が来るといいな。
